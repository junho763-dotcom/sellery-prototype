# Sellery — 인플루언서 공동구매 중개 플랫폼 프로토타입

브랜드사와 인플루언서(셀러)를 잇는 공동구매 중개 플랫폼 **셀러리(Sellery)** 의 클릭 가능한 UI/UX 프로토타입입니다.

단일 `index.html` (의존성 없음, 정적 호스팅). 마스터 모드로 셀러 센터 / 브랜드 센터 / 관리자 창구를 탭으로 전환하며 전체 플로우를 테스트할 수 있습니다.

## 구현된 플로우

상품 등록 → 검수 → 샘플 요청/승인/배송/테스트 → 공구 일정 제안/승인(기간 독점 캘린더) → 기간 한정 링크 → 판매(실시간 매출) → 종료 → D+21 교환·환불 기간 → 브랜드/셀러 정산 → 재공구

## 주요 기능

- 캠페인 스레드 (채팅 + 시스템 이벤트 타임라인, 연락처 유출 감지)
- 인플루언서 갤러리 + 브랜드의 공구 직접 제안(역제안)
- 익명 셀러 스카우트 (유료 레퍼런스 열람 → 제안 수락 시 신원 공개 + DM)
- 셀러 등급/랭킹 (등급별 수수료 보너스, 익명 리더보드)
- 실시간 매출 대시보드 (7일 차트, 주문 피드, 판매 시뮬레이션)
- 발주서 CSV 다운로드 / 이메일 자동 발주 (시뮬)
- 정산 시뮬레이션 (PG 2.9% / 셀러 수수료율 / 플랫폼 7% / 원천징수 3.3%)

데이터는 브라우저 localStorage에 저장됩니다. 우측 상단 "데이터 초기화"로 시드 데이터로 리셋.

> 프로토타입 전용 — 실제 결제·인증·서버 없음.
